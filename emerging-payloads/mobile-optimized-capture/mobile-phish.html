🔍 Mobile Phishing Characteristics (for security teams)

  • Viewport meta tag optimizes for mobile
  • 16px input font prevents iOS auto-zoom (more convincing)
  • Touch-friendly large buttons (48px+ tap targets)
  • Real phishing: URL bar often hidden or shows trusted subdomain
  • Form action would POST to attacker server
  • SSL cert on lookalike domain creates false trust
