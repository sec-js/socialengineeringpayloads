# Mobile Phishing: fake-update

> **⚠️ DISCLAIMER**: Educational purposes ONLY. Do not use without authorization.

## Overview
Mobile-targeting social engineering technique: FAKE UPDATE

## Why Mobile Targets Are Growing
- Smaller screens make URL inspection difficult
- High trust in SMS vs email
- BYOD devices often lack enterprise security controls
- QR codes bypass traditional URL analysis

## MITRE ATT&CK
- **T1566.002** — Phishing: Spearphishing Link (Initial Access)
- **T1056.003** — Input Capture: Web Portal Capture (Collection)

## Detection
- Mobile MDM monitoring for phishing indicators
- SMS gateway analysis
- QR code scanning policies

## Mitigation
- Mobile Device Management (MDM) policies
- Mobile threat defense solutions
- User training on mobile phishing recognition
